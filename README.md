# Irish Prajapati — Portfolio

Next.js 15 app with Tailwind CSS and Framer Motion.

## Prerequisites

- Node.js 20+

## Setup

```bash
rm -rf node_modules .next
npm install
```

## Scripts

| Command | Purpose |
|--------|---------|
| `npm run dev` | Local development (http://localhost:3000) |
| `npm run build` | Production build |
| `npm start` | **Production** server (run after `npm run build`) |

Do **not** use Create React App commands; this project is not `react-scripts`.

## Deploy

[Vercel](https://vercel.com): import the repo — framework **Next.js**, defaults are correct.
